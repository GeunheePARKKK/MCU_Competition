실물 확인 사항과 보정 전제

이 기록은 사용자가 실물 시험 후 알려준 내용이다. 코드의 컴파일·모의 검사 결과와 실제 기구 보정 완료 여부를 구분한다.

최신 인계 상태

  • 두 번째 홀센서는 추가 부품을 찾지 못해 실물 시험을 보류한다. 고장 판정이 아니다. train_hall_test는 준비·컴파일·모의 검사만 완료했고, 2개 센서의 실물 성공으로 기록하지 않는다.
  • 현재 확인된 홀센서는 TRAIN 칩 23번의 1개다. 향후 추가 OUT 연결은 TRAIN 칩 24번이며, 통합 코드는 아직 첫 센서만 사용한다.
  • 사용자가 첨부한 PSD·TRAIN 회로 사진 원본을 handoff_images에 보존한다. 이름표 사진은 부품 위치 설명용이며, 사진만으로 미세 배선·전압·소자 극성을 검증한 것이 아니다.
  • 처음 보는 사람용 안내는 START_HERE.md로 모은다. 이번 정리는 문서·사진만 변경하며 구동 코드·핀·속도값은 바꾸지 않는다.

서보 배치

핀 번호는 ATmega328P DIP-28의 물리적인 다리 번호다.

PSD 16번 D10 / PB2 기계 연결·해제 동작 확인. 정확한 모델·정품 여부는 확인하지 않음

양쪽 15번은 SG90 호환품이다. 같은 펄스 명령을 보냈다고 같은 실제 각도로 움직인다고 가정하지 않는다. 16번 서보를 정품 SG90이라고 단정하지 않는다. 두 호환품끼리도 보정값을 공통으로 쓸 수 있다고 미리 가정하지 않는다.

두 서보의 신호선은 기존 15번·16번을 유지한다. 한 개씩 시험한다는 것은 선택한 채널에만 명령을 출력한다는 의미이며, 설계에서 서보 하나를 제외한다는 의미가 아니다.

현재 확인된 범위

  • TRAIN 서보 두 개와 주행 모터: 사용자가 개별 동작 성공을 보고함.
  • PSD: USBasp 연결 문제를 해결한 뒤 서보 시험 동작 성공을 보고함.
  • 모터: 시험 메뉴의 80·120·160·200에서 모두 잘 돌았다고 보고함. 사용자는 더 느린 주행을 선호하지만, 현재 속도 설정은 일단 그대로 두기로 함.
  • 서보 시험의 1400·1500·1600µs는 움직임 확인용 명령이다. 실제 각도를 측정했거나 문 열림·닫힘·기계 해제 위치로 확정한 값이 아니다.
  • 실제 기구 장착 상태, 각 채널의 목표 위치·방향·허용 범위는 아직 확정되지 않았다.

다음 코드에서 분리해야 할 설정

각 보드에 별도 설정을 둔다. 보드 간 또는 채널 간에 값을 자동으로 복사하지 않는다.

채널 따로 정할 목표값
TRAIN 15번 문 닫힘 / 문 열림 펄스값
TRAIN 16번 기구 연결 / 기구 해제 펄스값
PSD 15번 문 닫힘 / 문 열림 펄스값
PSD 16번 기구 연결 / 기구 해제 펄스값

목표값은 µs 단위로 기록하고 실제 움직임을 함께 확인한다. 각 채널의 방향, 기구 간섭 없는 범위, 이동에 필요한 시간도 따로 확인한다. 넓은 범위를 자동으로 훑거나, 같은 각도 명령이면 같은 실제 위치라고 가정하지 않는다.

기구가 아직 없으면 임시 시연 위치와 실제 기구 보정값을 구분한다. 기구를 장착한 뒤에는 다시 보정한다. 호환품의 차이만으로 고장이라고 단정하지 않는다.

유지할 사용자 선택

  • 문 센서는 당분간 가상 입력을 유지한다. 가상 V1은 실제 문 닫힘·잠금 확인이 아니다.
  • 단독 구동 시험은 양쪽 모두 각 보드의 칩 4번 버튼 하나로 한다. 짧게 누르면 선택, 1초 이상 누르면 실행, 손을 떼면 출력 중단. 서보 명령은 최대 1초, TRAIN 모터는 최대 0.7초다.
  • PSD에 26번 선택 버튼이 있다고 가정하거나 추가하도록 반복 안내하지 않는다. 단독 시험에서 26번·KW11 조작은 필요 없다.
  • 기존 통합 코드의 PSD 4번 비상정지와 단독 시험의 4번 선택/실행은 서로 다른 모드다. 현재 통합 코드는 실제 서보·모터 출력을 끈 상태다.
  • 현재 구동 시험 성공은 자동 운행·실제 문 안전 확인 완료를 의미하지 않는다. 다음 단계는 채널별 위치 설정 후, 가상 문 입력을 명시한 모형용 통합 시험이다.
  • 원작업 폴더는 보존하고, 팀 전달본은 별도 ZIP으로 제공한다. 요청하지 않은 모터 속도 변경은 하지 않는다.
