# TRAIN–PSD 팀 전달본

**ZIP을 먼저 전부 압축 해제하고 `00_먼저읽기.html`을 더블클릭한다.** 사진·현재 상태·사용할 코드·다음 작업을 한곳에서 볼 수 있다. 인터넷 없이 읽을 수 있으며 Markdown 원본도 포함했다.

1. [작업 인계 요약](START_HERE.md)을 읽는다.
2. 새 PC라면 [설치·업로드 안내](SETUP.md)를 따른다.
3. 목적에 맞는 스케치를 선택한다. TRAIN·PSD용을 바꾸어 올리지 않는다.

| 폴더 | 용도 |
| --- | --- |
| `train_sketch` / `psd_sketch` | 양쪽 무선·표시·가상 문 순서 시험. **실제 모터·서보는 OFF** |
| `train_actuator_test` | TRAIN 서보 2개·모터 개별 시험 |
| `psd_actuator_test` | PSD 서보 2개 개별 시험 |
| `train_hall_test` | 홀센서 2개 LCD 시험. 추가 부품을 찾을 때까지 **보류** |
| `handoff_images` | 부품 이름표 사진과 원본 |
| `tests` | 개발자용 모의 검사. **보드에 업로드하지 않는다** |

현재는 주요 부품의 기본 동작 확인 단계다. 실제 문 센서는 가상이며, 자동 구동 통합·실제 기구·최종 전원 검증은 아직 남아 있다. 다음은 서보 4개를 각각 보정하는 작업이다.

필요할 때만 [서보·모터 시험](ACTUATOR_TEST.md), [가상 순서·오류 복구 시험](INTEGRATED_TEST.md), [부품별 보정 전제](HARDWARE_NOTES.md)를 참고한다. HTML과 MD는 같은 내용이며 MD를 수정해도 HTML이 자동 갱신되지는 않는다.

전달용 문서 경로만 정리했고 스케치 소스는 작업본과 동일하다. 오래된 배선 시험 스케치·이전 ZIP·빌드 파일·임시 파일·개인 PC 설정은 제외했다. 파일별 확인값은 `SHA256SUMS.txt`에 있다.
