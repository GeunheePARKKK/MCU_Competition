가상 문 순서·표시·오류 복구 시험

양쪽에 rain_sketch와 psd_sketch를 올리는 시험이다. 모터·서보는 OFF이며, 실제 자동 구동 시험이 아니다. 단독 구동 시험 조작과 구분한다. 현재 PSD의 칩 26번 화면전환 버튼은 없으므로 A3 조작은 생략한다. 새 버튼을 달라는 안내가 아니다.

2. 버튼과 배선

확인된 배선을 바꾸지 않는다. 배선 변경 시에는 전원을 끈다.

역할 PSD의 핀 ATmega328P DIP 실제 다리 연결
START/수동 복구 D5 / PD5 11번 버튼 반대편 GND
LCD 화면 전환 — 현재 미장착 A3 / PC3 26번 코드상 배정만 있음. 이 입력 시험은 생략
비상정지 D2 / PD2 4번 활성 시 GND
595 DATA A0 / PC0 23번 U1 14번만
595 CLOCK A1 / PC1 24번 U1·U2 11번
595 LATCH A2 / PC2 25번 U1·U2 12번
595 /OE D3 / PD3 5번 U1·U2 13번, 10kΩ으로 5V 풀업
부저 구동 D6 / PD6 12번 1kΩ을 거쳐 트랜지스터 B
  • U1은 LED1~8, U2는 LED9와 세그먼트다.
  • U1 9번 → U2 14번. 14번끼리 연결하지 않는다. U2 9번은 미연결.
  • 두 595의 16번=5V, 8번=GND, 10번=5V. 각 칩의 16·8번 사이 104 커패시터 하나씩.
  • LED 각각: 해당 595 출력 → 1kΩ → LED + → LED − → GND. HIGH일 때 켜지는 배선이다. 시작/전체 꺼짐 값도 0000으로 수정했다. /OE 풀업은 기존처럼 유지한다.
  • 세그먼트 각각: U2 출력 → 1kΩ → A~G 해당 다리. 3·8번=GND, 4번=C, 5번=DP 미연결.
  • LED 9개와 세그먼트 7개에 각각 저항을 넣는다. 공통선 저항 하나로 대체하지 않는다.
  • 부저 +=5V, −=트랜지스터 C, E=GND. 실제 부품의 B/C/E 배열과 기존 저항 배선을 유지한다.
  • 기본은 확인된 수동 부저다. 능동 부저라면 psd_config.h의 PSD_ACTIVE_BUZZER를 1로 바꾸고 PSD만 재컴파일한다.
  • 양쪽 KW11: COM→GND, NC→D4/PD4/실제 6번. 눌림 HIGH.
  • TRAIN 홀센서 OUT: A0/PC0/실제 23번. PSD A0와는 서로 다른 MCU의 핀이다.
  • LCD는 양쪽 모두 A4(SDA)/A5(SCL), 0x27. nRF는 기존 SPI·레벨 변환·3.3V 전원을 유지한다.
  • 모터·서보 구동 신호는 OFF 유지. 가능하면 시험 중 모터·서보 전원도 분리한다.

예전 배선 시험 스케치는 전달본에 포함하지 않았다. LED는 아래 표의 출력 배치를 따른다. 단, 그곳의 옛 단독 시험은 LOW=켜짐 배선용이다. 현재 GND 연결 상태에서는 그 스케치를 다시 올리지 않고 본 psd_sketch를 사용한다.

버튼 동작 차이: 본 프로그램의 D5는 출발/복구 버튼이다. 단독 배선 시험처럼 일시정지/이어하기를 하지 않는다. A3는 눌렀다 놓을 때 한 번 바뀌며, 길게 눌러도 반복하지 않는다. 부팅할 때 누른 버튼을 놓는 것만으로 전환되지 않는다.

3. 한 사람이 진행하는 한 사이클

양쪽 KW11을 놓은 상태로 전원을 켠다. 두 가상 문은 V0부터 시작한다. 각 KW11을 눌렀다 놓을 때 V0↔V1이 바뀌며, 계속 누르고 있을 필요는 없다.

단계 할 일 기대 결과
준비 양쪽 KW11을 한 번씩 눌렀다 놓아 V1. TRAIN 홀센서에 1개 자석 L1, 양쪽 READY. LED1·2
화면 확인 현재 26번 버튼이 없으므로 이 조작은 생략 기본 디버그 화면으로 진행
출발 PSD 칩 11번(D5)를 짧게 누르기 TRAIN RUN. LED3. 실제 모터는 OFF
감속 자석을 0.3초 이상 떼고 2개를 대기 SLOW. LED4
정차 2개를 0.3초 이상 떼고 3개를 대기. T-OPEN이 나올 때까지 유지 STOP → T-OPEN. 정차 확인 후 LED5·6, 도착음
TRAIN 열기 TRAIN KW11 한 번: V1→V0 PSD OPENING으로 진행
PSD 열기 PSD KW11 한 번: V1→V0 문 열림 대기 5초 → COUNT
카운트다운 별도 조작 없이 보기 두 LCD와 세그먼트 5→4→3→2→1→0, 숫자가 바뀔 때 짧은 소리
TRAIN 닫기 T-CLOSE가 된 뒤 TRAIN KW11 한 번: V0→V1 PSD CLOSING으로 진행
PSD 닫기 PSD CLOSING이 된 뒤 PSD KW11 한 번: V0→V1 DONE. LED8, 완료음
반복 자석을 0.3초 이상 떼고 다시 1개. READY에서 새 D5 다음 사이클

열기와 닫기 모두 TRAIN → PSD 순서다. 각 닫기 단계가 V0을 한 번 확인한 뒤 V1이 되어야 새 닫힘으로 인정한다. 이전 단계에서 미리 닫아 두면 완료되지 않을 수 있다. 카운트다운 표시를 중간에 A3로 전환해도 5→0 표시는 계속 유지한다. PSD의 카운트다운은 유효하게 수신한 TRAIN 값을 표시한다. 무선 패킷 자체가 손실되면 일부 숫자를 못 볼 수 있다.

유지한 자석 설정

기준 ADC 508, 변화량 abs(ADC - 508)으로 N/S 양극성을 모두 처리한다.

묶음 변화량 허용 범위 용도
1개 15~25 시작/복구 위치
2개 41~51 감속
3개 60~82 정차

3개 ADC 허용 범위는 426448 또는 568590이며 443도 포함한다. 각 범위 30ms 유지, 묶음 사이 무자석 상태 150ms 이상 확인. 자석 개수를 직접 세는 것이 아니라 정해진 거리에서 측정한 자기장 크기를 분류한다. 3개 정차 인식 후 0.3초 뒤 한 번 재확인하므로 T-OPEN까지 유지한다.

RUN/SLOW 자석 대기는 각각 2분, 각 문 확인은 1분, 상대 문 응답은 65초. 통신은 첫 유효 수신 후 약 2초간 새 유효 패킷이 없으면 오류다. 첫 연결 전 INIT에서 기다리는 것은 통신두절과 구분한다.

4. LED·세그먼트·부저의 의미

본 프로그램에서는 여러 상태 LED가 함께 켜질 수 있다. 단독 배선 시험처럼 항상 하나씩 켜는 것이 아니다.

LED 의미 595 출력
1 양쪽 READY 상태, PSD 가상 닫힘 U1 15번 QA
2 PSD에서 본 유효 무선 연결 L1 U1 1번 QB
3 RUN U1 2번 QC
4 SLOW U1 3번 QD
5 정차 재확인 통과 후 문 동작~DONE U1 4번 QE
6 TRAIN 문 열기/닫기 단계 U1 5번 QF
7 PSD 문 열기/닫기 단계 U1 6번 QG
8 TRAIN DONE + PSD CLOSED + PSD 가상 닫힘 U1 7번 QH
9 일반 오류: 계속 켜짐 / 비상정지: 깜빡임 U2 15번 QA

LED는 단계·가상 상태 표시다. 실제 문 위치, 실제 열림 완료나 실제 모터 정지를 측정한 표시가 아니다. LED1 역시 출발 조건 전체에 대한 독립 안전 보증이 아니며 실제 출발 허용은 FSM이 판단한다.

  • 세그먼트: COUNT에서만 5~0, 일반 오류에서 E, 그 외 및 비상정지에서는 꺼짐. DP는 항상 미사용.
  • 부저: 정차 재확인 통과 후 짧은 도착음, 숫자 변경 시 한 번, DONE에 완료음.
  • 일반 오류: 약 2초마다 짧게. 비상정지: 빠르게 반복. 오류/비상정지는 정상 안내음을 우선 차단한다.
  • 같은 상태의 무선 패킷을 반복 수신한다고 음을 처음부터 다시 재생하지 않는다.
  • 소리는 센서의 실제 성공 판정이 아니라 코드의 상태를 안내한다.

5. LCD에서 보는 값

  • D=디버그, N=일반. 일반 화면에는 단계와 SIM: MOTORS OFF가 나온다.
  • TRAIN D 첫 줄: T=단계, L=통신, E=기다리는 자석. 예: D T:SLOW L1E3.
  • TRAIN 둘째 줄: A=ADC, D=변화량, M=분류. 다른 페이지의 V=TRAIN 가상 닫힘, P=PSD 가상 닫힘.
  • PSD D 첫 줄: P=PSD 단계, L=통신. 둘째 줄은 TRAIN 단계와 V/문 명령, 또는 입력/무선 진단값.
  • DC/DO/DH/DR=닫기/열기/유지/해제 명령. 실제 서보 동작이 아니다.
  • B=START 눌림, PSD의 E=물리 비상정지 입력. TRAIN 첫 줄 E(자석 번호)와 구분한다.
  • R=무선 초기화 결과(정상 0), K=마지막 패킷 검사 결과(정상 0, 초기 미수신 1, 버전 불일치 3).
  • 오류 중에도 첫 줄 F 번호와 L은 유지한다. TRAIN 디버그 둘째 줄에서는 ADC를 계속 확인할 수 있다.
  • COUNT 중에는 ADC 페이지보다 카운트다운이 우선한다. 0을 표시하는 0.3초도 숨기지 않는다.
  • LCD 입력이 인식되지 않거나 I2C 시간초과로 갱신이 중단되면 배선·주소를 확인하고 리셋한다. LCD 고장을 안전 센서 대신 감시하는 기능은 아니다.

F2 통신 문제
F3 동작 중 상대 재부팅
F4 홀센서 이상 또는 자석 대기 시간 초과

새 닫힘 재확인 시험

정상 사이클을 먼저 한 번 마친 뒤 아래 시험은 각각 따로 수행한다.

  1. TRAIN을 닫아 PSD CLOSING으로 간다.
  2. PSD를 닫기 전에 TRAIN KW11을 다시 눌렀다 놓아 V1→V0으로 만든다.
  3. TRAIN F6 및 오류 표시가 나오는지 확인한다. PSD를 나중에 닫아도 DONE이 되면 안 된다.

또는 정상 DONE 뒤 TRAIN만 열어 F6, 별도 정상 사이클의 DONE 뒤 PSD만 열어 F7을 확인한다. 일반적인 문 열기 단계에서 V0이 되는 것은 오류가 아니다.

수동 복구

  1. 비상정지 입력을 해제한다. PSD E1이면 아직 입력이 활성이고, E0이면 해제된 상태다.
  2. L1을 확인하고 양쪽 V를 1로 만든다. V0인 보드의 KW11만 눌렀다 놓는다.
  3. 자석을 0.3초 이상 뗀 뒤 1개 자석을 대어 M1을 만든다.
  4. PSD 칩 11번(D5) 한 번은 복구 요청이다. 약 1초 기다려 READY가 되는지 확인한다.
  5. 다시 출발하려면 READY에서 D5를 새로 누른다. 복구만으로 출발하지 않는다.

복구 요청은 최대 15초 유지된다. 안 되면 L/V/M과 원인 입력을 다시 확인한다. A3는 화면만 바꾸며, FAULT나 E-STOP을 해제하지 않는다. 전원을 끄거나 리셋하면 가상 문과 화면 모드도 초기화된다.
