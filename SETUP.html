처음 읽기 · 설치·업로드 · 전체 압축 해제 후 사용

새 PC에서 열고 업로드하기

1. 설치

Arduino IDE를 준비한다. 보드 매니저에서 Arduino AVR Boards 1.8.6, 라이브러리 매니저에서 LiquidCrystal I2C 1.1.2(Frank de Brabander)를 설치하면 기존 검증 환경과 맞출 수 있다. 최초 설치에는 인터넷이 필요하다. IDE와 외부 라이브러리 자체는 이 ZIP에 포함하지 않았다.

  • LiquidCrystal_I2C.h: No such file이면 위 LCD 라이브러리 설치와 IDE의 스케치북 경로를 확인한다.
  • 같은 이름의 다른 LCD 라이브러리가 여럿 설치돼 있으면 어느 버전이 선택됐는지 확인한다.
  • Wire는 AVR 보드 패키지에 포함된다. 이 전달본에는 별도 TrainPsdComm이나 Servo 라이브러리가 필요하지 않다. 필요한 통신 소스는 스케치 폴더에 들어 있다.

2. 파일 선택

ZIP 안에서 바로 열지 말고 짧은 경로에 전체 압축 해제한다. 예를 들어 문서 폴더 아래에 둔다. 각 스케치 폴더 이름과 .ino 이름을 유지하고 .h·.c·.cpp를 함께 둔다.

  • 부품 재시험: TRAIN은 train_actuator_test/train_actuator_test.ino, PSD는 psd_actuator_test/psd_actuator_test.ino.
  • 가상 연동 시험: train_sketch/train_sketch.ino와 psd_sketch/psd_sketch.ino를 각각 해당 보드에 올린다.
  • tests 안의 스케치는 PC 모의 검사용이며 실물 보드에 올리지 않는다.

3. 업로드

  1. 모터·서보 전원을 끄고 해당 MCU의 USBasp 연결과 전원을 확인한다.
  2. IDE에서 보드: Arduino Uno, 프로그래머: USBasp를 선택한다. 실제 회로는 ATmega328P DIP-28, 16MHz 기준이다.
  3. 먼저 검증/컴파일하고 스케치 → 프로그래머를 사용하여 업로드한다. 퓨즈·부트로더를 임의로 바꾸지 않는다.
  4. 완료 메시지와 LCD를 확인한다. USBasp는 시리얼 모니터용 포트가 아니므로 COM 포트가 생기지 않는 것만으로 오류는 아니다. 장치가 인식되지 않으면 USBasp의 운영체제 드라이버 상태를 먼저 확인한다.

target doesn't answer가 나오면 업로드 실패다. 전원·공통 GND·RESET·MOSI·MISO·SCK 배선을 확인한다. 경고만 보고 성공으로 판단하거나 강제 진행하지 않는다.

4. 기본 조작

단독 구동 시험에서 각 보드 칩 4번 버튼: 짧게=선택 / 1초 이상=실행 / 놓으면 출력 중단이다. P15·P16은 서보의 칩 핀 번호다. 모터 시험은 바퀴를 띄운다. 26번 버튼을 새로 추가할 필요는 없다.

통합 PSD 코드에서는 같은 칩 4번이 비상정지다. 단독 시험 조작과 혼동하지 않는다. 구동 시험은 무선을 쓰지 않으므로 반대쪽 통합 보드에 통신 오류가 떠도 그 보드는 꺼두고 단독 시험을 진행할 수 있다.

실제 문 입력은 아직 가상이며 기존 통합 코드의 모터·서보 출력은 OFF다. 출력 차단 설정만 풀어서 실제 운행에 사용하지 않는다.
